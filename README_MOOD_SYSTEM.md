## 🎯 كيفية الاستخدام

### للأطفال 👶

1. امسح QR Code الخاص بك
2. اختر حالتك المزاجية:
   - 😄 **سعيد** (أخضر)
   - 😐 **عادي** (برتقالي)
   - 😢 **حزين** (أزرق)
3. تم! سيتم حفظ اختيارك ✅

### للمعالجين/الإدارة 👨‍⚕️

1. **توليد QR Codes:**
   - اذهب إلى: `/mood/qr-codes`
   - اطبع كود لكل طفل
   - علقه في مكان واضح

2. **متابعة النتائج:**
   - اذهب إلى: `/mood/dashboard`
   - شاهد الإحصائيات
   - تابع آخر 50 تسجيل

## 🔗 الروابط المهمة

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| 🧪 **اختبار** | `/mood/test` | صفحة اختبار شاملة |
| 📊 **Dashboard** | `/mood/dashboard` | إحصائيات ومتابعة |
| 🔗 **QR Codes** | `/mood/qr-codes` | توليد أكواد QR |
| 😊 **اختيار** | `/mood/{id}` | صفحة الطفل |

## 🏗️ البنية التقنية

### Backend
```
src/
├── Entity/
│   └── MoodTracking.php          # Entity رئيسي
├── Repository/
│   └── MoodTrackingRepository.php # دوال الاستعلام
└── Controller/
    └── MoodController.php         # 5 routes
```

### Frontend
```
templates/mood/
├── select.html.twig      # صفحة اختيار المشاعر
├── success.html.twig     # صفحة النجاح
├── dashboard.html.twig   # لوحة التحكم
├── qr_codes.html.twig    # QR codes
└── test.html.twig        # صفحة اختبار
```

### Database
```sql
mood_tracking
├── id (PK)
├── patient_id (FK)
├── mood (happy/neutral/sad)
└── created_at (timestamp)
```
